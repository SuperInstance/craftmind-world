# Paper Minecraft Server — Sitka / Craftmind League (dev)

A Paper server on the household LAN, hosted on the Orin. Bot clients from
the Thor (the agent community) and human players on the LAN join here.

## What is installed

- **Paper 26.1.2, build 74** (`paper.jar`, 52,893,229 bytes)
  - SHA-256: 1d70b1dab9cf4a6de615209a536f3a45a2186240253c428213ce2188ab95e5f7
    (matches the value published by the official PaperMC Fill API)
  - Protocol 775
  - **Version pin (2026-11-05):** the server is pinned to the 26.1
    line because the bot client library on the Thor
    (`minecraft-data` 3.119.0, used by the Craftmind league bots)
    cannot yet load data for 26.3 — 26.1 is the newest joinable
    version. Revisit when `minecraft-data` ships 26.3 support.
  - The previous jar (Paper 26.3, build 242) is kept alongside as
    `paper-26.3-242.jar`. The world generated by 26.3 is preserved
    at `world-26.3-backup/` (Minecraft worlds do not downgrade
    safely); 26.1 generated a fresh world in `world/`. The 26.3
    world was empty (no player had ever joined).
- **Java 25** — Eclipse Temurin JRE 25.0.5+8, aarch64, at `~/jdk-25/`
  (Minecraft 26.1+ requires Java 25; Ubuntu 24.04 apt only offers 21,
  which is also installed system-wide but is NOT used by this server.)
- Server directory: `~/minecraft-server/` (world in `world/`, plus
  `world_nether/` and `world_the_end/` once visited)

## Service

Runs as a systemd **user** service named `minecraft-paper`
(unit: `~/.config/systemd/user/minecraft-paper.service`), enabled at
boot; linger is on for user `casey`, so it survives logout and reboot.

```sh
export XDG_RUNTIME_DIR=/run/user/1000   # needed over plain SSH sessions
systemctl --user status  minecraft-paper
systemctl --user start   minecraft-paper
systemctl --user stop    minecraft-paper    # graceful: Paper saves and exits on SIGTERM
systemctl --user restart minecraft-paper
```

JVM flags: `-Xms1G -Xmx2G -XX:+UseG1GC`. The Orin has ~7.5 GB RAM total
and the desktop session uses roughly half, so the heap is deliberately
kept at 2 GB; raise `-Xmx` in the unit file only if the desktop is not
in use, then `systemctl --user daemon-reload && systemctl --user restart minecraft-paper`.

## Console and logs

- Log file: `~/minecraft-server/logs/latest.log` (rotated daily-ish into the same folder)
- Service journal: `journalctl --user -u minecraft-paper -f`
- The systemd service has no interactive console attached. To issue
  server commands interactively, stop the service and run the jar in a
  terminal once:
  `cd ~/minecraft-server && ~/jdk-25/bin/java -Xms1G -Xmx2G -jar paper.jar nogui`
